# growi-plugin-editor-toolbar-top

GROWI 7.5.x の標準 Markdown エディターで、下部の編集ツールバーを編集欄上部へ表示するスクリプトプラグインです。

## 特徴

- GROWI 本体のファイルを変更しません
- DOM ノードを別の場所へ移動せず、実物のツールバーを上部へ固定表示します
- React の再描画で元に戻る問題を避けます
- View 画面には作用しません
- プラグインを OFF にすると元の下配置へ戻ります

## 対象

- GROWI 7.5.x
- GROWI 標準の CodeMirror エディター

## インストール

1. このリポジトリを GitHub に配置します。
2. GitHub Actions のビルドが成功し、`dist` が生成されたことを確認します。
3. GROWI の「管理画面 → プラグイン」にリポジトリ URL を入力します。
4. インストール後、プラグインを ON にします。
5. ブラウザを強制再読み込みします。

## 元に戻す

プラグインカードを OFF にして強制再読み込みしてください。
